# physics-force-cards

物理基礎「力のカードゲーム」の問題用画像と問題データです。
Quizizz（Wayground）などのクイズアプリに、画像URLを渡すために公開しています。

## Web版の演習

https://phys-ken.github.io/physics-force-cards/quiz/

学校のアプリが開けないときに使う演習ページです（`quiz/`）。記録は送信しないので、解き終わったら回答記録の画像を保存して提出してください。

## 画像URL

```
https://raw.githubusercontent.com/phys-ken/physics-force-cards/main/<ファイル名（URLエンコード）>
```

| 種類 | 枚数 | ファイル名 |
|---|---:|---|
| 単体カード | 61 | `01_S01-01_….png` 〜 `61_…png` |
| 2×2 4択パネル | 61 | `P01_….png` 〜 `P61_….png` |
| 1×2 2力関係判定パネル | 18 | `R01_….png` 〜 `R18_….png` |

## データ

- `questions_bank.json` — カード・問題文・選択肢・正答・解説・画像URL
- `Quizizz_*.xlsx` — Quizizz 一括インポート用（6ファイル）
- `力のカードゲーム_問題バンク一覧.xlsx` — カード一覧・問題一覧
